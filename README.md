Situation: Noticed the need for a tool to benchmark disk I/O performance during systems-level development.

Task: Design and implement a utility to measure read/write throughput using various block sizes on Linux.

Action: Built a C++17 tool to generate test data, perform sequential reads/writes, and measure latency and throughput across 4 KB–1 MB blocks.

Result: Delivered a lightweight analyzer that provided actionable performance metrics (up to 5× speed variance), aiding storage tuning and demonstrating strong systems programming skills.
